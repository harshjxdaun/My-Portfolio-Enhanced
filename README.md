# Harsh Jadaun Portfolio

A small, static portfolio site with separate pages and shared styling.

## Project structure

harsh-portfolio/
├── index.html
├── projects.html
├── work.html
├── skills.html
├── contact.html
├── blog.html
├── css/
│   └── style.css
└── js/
    └── main.js

## Open it

Open `index.html` in a browser. Use the navigation at the top to switch between pages. The theme button switches between dark and light mode and remembers the choice in that browser.

Update the page text and skills in the corresponding HTML files. Add new styles in `css/style.css` and interactive behavior in `js/main.js`.
